1. **Test Case ID:** TC_FT_001  
   **Test Name:** Verify functionality when user provides valid input for `board_type = 'none'`.  
   - **Test Steps:**  
     1. Launch the application.  
     2. Set `board_type` to `'none'`.  
     3. Provide valid input in the prompt input field.  
   - **Input:** Set `board_type` = `'none'` and enter `"JIRA-1234"`.

2. **Test Case ID:** TC_FT_002  
   **Test Name:** Verify behavior when no user input is provided for `board_type = 'none'`.  
   - **Test Steps:**  
     1. Launch the application.  
     2. Set `board_type` to `'none'`.  
     3. Leave the input field empty and attempt to proceed.  
   - **Input:** Set `board_type` = `'none'` with no input provided.  
   - **Expected Output:** The system should display an appropriate error message prompting the user to provide input.  

3. **Test Case ID:** TC_FT_003  
   **Test Name:** Verify system validation for invalid or special character input when `board_type` is `'none'`.  
   - **Test Steps:**  
     1. Set `board_type` to `'none'`.  
     2. Enter invalid or special characters like `@#*&!` in the input field.  
   - **Input:** Set `board_type` = `'none'` and input `@#*&!`.  
   - **Expected Output:** The system should reject the input and display a validation error.  

4. **Test Case ID:** TC_FT_004  
   **Test Name:** Verify system behavior when `board_type != 'none'`.  
   - **Test Steps:**  
     1. Launch the application.  
     2. Set `board_type` to a value other than `'none'` (e.g., `"basic"`).  
   - **Input:** Set `board_type` = `"basic"`.  
   - **Expected Output:** The system should not prompt for additional input and should proceed as normal. 

5. **Test Case ID:** TC_FT_005  
   **Test Name:** Verify the behavior when a valid `board_type` is changed to `'none'`.  
   - **Test Steps:**  
     1. Set `board_type` to `'basic'`.  
     2. Change it to `'none'`.  
     3. Provide required user input.  
   - **Input:** Input sequence: Initial `board_type = "basic"` > Change to `board_type = "none"` > Provide input "JIRA-5678".  
   - **Expected Output:** The system should prompt for user input immediately upon changing `board_type` to `'none'`.
